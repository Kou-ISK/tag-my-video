# Paint: 戦術描画と対応範囲

2026-09-10時点。Playlistの描画編集モードを **Paint** と呼ぶ。Hudl Studioの名称・素材をアプリへ流用せず、分析者の操作に必要な機能を独自実装する。操作方法は[ユーザーガイド](user-guide.md#tacticsの動き平面保存済み)。

## 公式資料から確認した用途と実装

| 分析者の操作                     | Paintの対応                                                                         | 残る差分                                                           |
| -------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 選手・移動・間隔を強調する       | ビーム、ディスク、選手リンク、曲線矢印、領域、文字、自由描画、レイヤー、Undo        | 画像素材、複数図形グループ、波形矢印、選手切り抜き移動は未対応     |
| 映像に図形を追従させる           | 表示区間、平行移動キー、区間タイムライン、現在位置の手修正                          | 回転・拡大率・形状の時間変化は未対応                               |
| 追跡を省力化する                 | 別デコーダーによる映像パターン追跡、信頼度低下時停止、適用/破棄、手修正位置から再開 | 選手の意味的識別、遮蔽後の再発見、カメラ移動の推定は未対応         |
| 芝に図形を置き、選手を手前にする | 芝色の自動抽出、手動色/許容範囲、再生・書き出しのクロマ処理                         | 芝と似たユニフォームや照明変化には手動調整が必要                   |
| ピッチ上の位置と距離を示す       | 既知の長方形を4点で手動較正、領域の透視投影、静的な線/矢印の概算距離                | ピッチ線の自動検出、カメラに追従する較正、3D高さ、速度計測は未対応 |
| アングルを切り替えて説明する     | 描画・較正・芝色をアングル別に保存し、二映像を書き出す                              | アングル間の3D座標対応や追跡の共有は未対応                         |
| よく使う表現をすぐ呼び出す       | 図形プリセット、Coachツール選択と4色の変更                                          | 画像付きパネル、複数図形テンプレートの共有、タイマーは未対応       |
| 説明した映像を共有する           | 移動描画と静止挿入の混在、アングル別クロマ、音声なし素材にも対応                    | 距離の数値と較正ガイドは編集補助であり映像には焼き込まない         |

Hudlの製品説明は自動追跡・自動較正・クロマ・複数アングルを主要機能としている。Paintはそれらの作業目的に対応する基盤を追加したが、同等の自動解析能力を保証するものではない。[Hudl Studio製品ページ](https://www.hudl.com/products/studio)

## 調査したUIと操作

- ツールとクリップ操作をCoach向けに絞り、よく使う色やツールを選べる構成を採用した。[Coach機能](https://www.hudl.com/blog/new-coach-mode-features-enhance-studio-feedback)、[2023年の追跡・Coach更新](https://www.hudl.com/blog/get-ahead-with-the-latest-features-for-studio)
- オブジェクトの表示区間とキーフレームを映像の下へ置き、位置を手修正して追跡を続けられる流れを採用した。公式更新履歴では、開始/終了位置、手修正後の追跡、グループ化、2026年7月の波形矢印なども確認した。[公式リリース履歴](https://www.hudl.com/releases/studio)
- 再利用については、最初に単一図形の形・スタイルを保存する範囲を実装した。画像や複数オブジェクトから成るパネルは別のデータ所有・編集契約が必要なため未対応と明示する。[カスタムパネル](https://www.hudl.com/blog/create-customised-panels-with-studio)
- 実寸の指定と投影領域を導入した。自動較正や3Dを装わず、カメラが動く場合の再較正をUIで案内する。[Hudl Japanの較正・計測紹介](https://note.hudl.jp/n/n2c8a21bb2828)

## 保存・制約

既存DrawingObjectに任意のmotionを追加する。時刻は注釈開始からの相対秒、位置は基準解像度のオフセット。既存の静止注釈とPlaylist順序を維持する。不正な拡張データは読込を拒否し、静止図形へ黙って変換しない。

- 動画描画は最大600秒、1図形256キー。追跡は1回20秒・10Hz、入力を最大640px幅へ縮小し、線形補間誤差1px以内の点を間引く。
- 追跡対象は図形の中心付近の模様。中心を選手の輪郭や模様へ合わせる。無地、急移動、遮蔽、似た対象が並ぶ場面では止まることがある。
- 動き/芝色処理の書き出しは1クリップ64図形・合計4096キーまで。上限超過はエラーとして通知する。
- 較正はアングルごとの単一平面で、既知の長方形を周囲の順に4点指定する。距離表示は同一平面上でのみ意味を持つ。
- プリセットは端末のローカル設定に最大24件。動きは保存しない。Playlistを渡してもプリセットやCoach設定は移転しない。

## 検証用Storybook

`Workspace/Playlist/Paint` の Interactive / Empty / Video Trackingを使用する。Video Trackingは4秒の合成映像を実際にデコードし、追跡→適用→位置編集→再追跡、平面較正、芝色抽出、プリセット挿入とUndoを試せる。追跡品質の実試合データによる評価は別途必要。
