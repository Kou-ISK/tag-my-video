# Paint: 戦術描画と対応範囲

2026-09-10時点。Playlistの描画編集モードを **Paint** と呼ぶ。Hudl Studioの名称・素材をアプリへ流用せず、分析者の操作に必要な機能を独自実装する。操作方法は[ユーザーガイド](user-guide.md#tacticsの動き平面保存済み)。

## 公式資料から確認した用途と実装

| 分析者の操作                     | Paintの対応                                                                                                   | 残る差分                                                           |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 選手・移動・間隔を強調する       | ビーム、ディスク、選手リンク、曲線矢印、領域、文字、自由描画、レイヤー、Undo                                  | 画像素材、複数図形グループ、波形矢印、選手切り抜き移動は未対応     |
| 映像に図形を追従させる           | 表示区間、平行移動キー、区間タイムライン、現在位置の手修正                                                    | 回転・拡大率・形状の時間変化は未対応                               |
| 追跡を省力化する                 | 別デコーダーによる映像パターン追跡、信頼度低下時停止、成功時自動反映・部分結果の適用/破棄、手修正位置から再開 | 選手の意味的識別、遮蔽後の再発見、カメラ移動の推定は未対応         |
| 芝に図形を置き、選手を手前にする | 芝色の自動抽出、手動色/許容範囲、再生・書き出しのクロマ処理                                                   | 芝と似たユニフォームや照明変化には手動調整が必要                   |
| ピッチ上の位置と距離を示す       | 既知の長方形を4点で手動較正、領域の透視投影、静的な線/矢印の概算距離                                          | ピッチ線の自動検出、カメラに追従する較正、3D高さ、速度計測は未対応 |
| アングルを切り替えて説明する     | 描画・較正・芝色をアングル別に保存し、二映像を書き出す                                                        | アングル間の3D座標対応や追跡の共有は未対応                         |
| よく使う表現をすぐ呼び出す       | 図形プリセット、Coachツール選択と4色の変更                                                                    | 画像付きパネル、複数図形テンプレートの共有、タイマーは未対応       |
| 説明した映像を共有する           | 移動描画と静止挿入の混在、アングル別クロマ、音声なし素材にも対応                                              | 距離の数値と較正ガイドは編集補助であり映像には焼き込まない         |

Hudlの製品説明は自動追跡・自動較正・クロマ・複数アングルを主要機能としている。Paintはそれらの作業目的に対応する基盤を追加したが、同等の自動解析能力を保証するものではない。[Hudl Studio製品ページ](https://www.hudl.com/products/studio)

## 調査したUIと操作

- ツールとクリップ操作をCoach向けに絞り、よく使う色やツールを選べる構成を採用した。[Coach機能](https://www.hudl.com/blog/new-coach-mode-features-enhance-studio-feedback)、[2023年の追跡・Coach更新](https://www.hudl.com/blog/get-ahead-with-the-latest-features-for-studio)
- オブジェクトの表示区間とキーフレームを映像の下へ置き、位置を手修正して追跡を続けられる流れを採用した。公式更新履歴では、開始/終了位置、手修正後の追跡、グループ化、2026年7月の波形矢印なども確認した。[公式リリース履歴](https://www.hudl.com/releases/studio)
- 再利用については、最初に単一図形の形・スタイルを保存する範囲を実装した。画像や複数オブジェクトから成るパネルは別のデータ所有・編集契約が必要なため未対応と明示する。[カスタムパネル](https://www.hudl.com/blog/create-customised-panels-with-studio)
- 実寸の指定と投影領域を導入した。自動較正や3Dを装わず、カメラが動く場合の再較正をUIで案内する。[Hudl Japanの較正・計測紹介](https://note.hudl.jp/n/n2c8a21bb2828)

## 保存・制約

既存DrawingObjectに任意のmotionを追加する。時刻は注釈開始からの相対秒、位置は基準解像度のオフセット。既存の静止注釈とPlaylist順序を維持する。不正な拡張データは読込を拒否し、静止図形へ黙って変換しない。

- 動画描画は最大600秒、1図形256キー。追跡は1回20秒・30Hz、入力を最大1280px幅へ縮小し、線形補間誤差1px以内の点を間引く。
- 「対象を指定して追尾」から選手の上半身を囲み、「この範囲を追尾」で解析する。図形とは独立した範囲内の特徴を使い、移動に合わせて特徴の再探索範囲も動かす。範囲は解析ごとの一時状態で、シーク・選択・クリップの変更で無効になる。無地・遮蔽・似た選手の交差では追尾が止まる、または外れる場合がある。
- 動き/芝色処理の書き出しは1クリップ64図形・合計4096キーまで。上限超過はエラーとして通知する。
- 較正はアングルごとの単一平面で、既知の長方形を周囲の順に4点指定する。距離表示は同一平面上でのみ意味を持つ。
- プリセットは端末のローカル設定に最大24件。動きは保存しない。Playlistを渡してもプリセットやCoach設定は移転しない。

## 検証用Storybook

`Workspace/Playlist/Paint` の Interactive / Empty / Video Trackingを使用する。Video Trackingは4秒の合成映像を実際にデコードし、追尾→自動反映→位置編集→再追尾、平面較正、芝色抽出、プリセット挿入とUndoを試せる。追跡品質の実試合データによる評価は別途必要。

編集は図形・表示時間・追尾・較正の調整用、プレゼン（旧Coach）は映像を広く見せて説明するための簡略操作です。両モードは同じ描画とUndo履歴を使い、プレゼンでの描画も保存されます。自動追尾はボタンから開始する画像追跡であり、再生時の全選手自動検出ではありません。

2026-09-10の検証: 部分遮蔽、明るさの変化、連続移動、特徴喪失を回帰テストへ追加した。公開の[OpenCV人物映像](https://github.com/opencv/opencv/blob/4.x/samples/data/vtest.avi)でも足元からの追従を確認したが、人物の交差・遮蔽で対象から外れる場合は残る。試合映像での精度を保証するものではなく、対象映像・時刻を指定して評価する必要がある。

### 2026-09-10: 選手グラフィックと追尾の精度改善

参照対象は[Hudl Studio 2.3.1の公式リリースノート](https://www.hudl.com/releases/studio)と[現行ダウンロード一覧](https://www.hudl.com/downloads/elite)。Connected Discの人数ドロップダウンが公式資料に記載されている。公開資料で確認できる操作を参照し、非公開の追尾実装や画面全体との同一性は主張しない。

選手リンクは足元を順にクリックして2〜15人を配置し、Enterまたは「リンクを確定」で保存します。Escで中止できます。作成後は「選手を追加」「末尾を削除」を使い、各中心をドラッグして調整します。追加点は長い区間の中点に配置されます。確定・変更はUndoできます。

- ディスクとビームの足元に薄い厚み・接地影・光沢を追加。リンク線の下地でピッチとの分離を改善した。編集、プレビュー、PNG出力は共通描画を使用する。立体感は描画表現であり、カメラの自動3D較正ではない。
- 追尾は0.25px刻みの位置補正を行い、通常探索で見失った場合に半解像度で移動量を推定して元解像度で再検証する。移動の合意は入力特徴の半数以上を必要とする。途中結果の適用、再追尾、Undoの契約は維持する。
- 0.5px/フレームの連続移動、探索幅を超える34px移動を回帰テストへ追加。公開人物映像の交差・遮蔽では誤追尾や停止が残るため、試合映像の精度保証とは区別する。

そのアングルで最初のディスク・リング・ビーム・選手リンクを追加した時に芝色を取得し、選手の背後に合成する設定を描画と同じUndo履歴で保存します。既存描画ではスタイルまたはピッチの「選手の背後に描画」から有効化・調整・解除できます。この設定はアングル内の描画全体に作用し、通常再生と書き出しにも引き継ぎます。色による分離のため、緑のユニフォームや芝以外の床では調整が必要です。

### Paintのキーフレームとキー操作

位置キーは右ペインの時刻一覧ではなく、描画タイムラインの◆から選択します。選択した点は横ドラッグ、または左右キーで時刻変更できます（左右は1/30秒、Shift併用で10/30秒。映像のフレームレートからの算出ではありません）。隣のキーとの順序を保ち、表示区間の外へは移動しません。密集した点はタイムラインを最大16倍に拡大して選択できます。

タイムライン上部には選択中の絶対時刻と基準位置からのX/Y移動量を表示します。数値は入力後にフォーカスを外すと反映します。「位置を削除」またはBackspace/Deleteは選択した点だけを削除します。開始点（相対0秒）は保存契約の基準なので、位置は編集できますが削除・時刻変更はできません。

描画そのものをキャンバスやレイヤー名で選択してBackspace/Deleteを押すと、その描画を削除します。Paint中はPlaylistのクリップ削除・矢印再生・クリップ移動のグローバルホットキーを無効にし、保存・書き出し・Undo/Redo・再生停止は維持します。文字入力欄は通常の文字編集を優先します。再生中や未選択時のBackspaceでクリップを削除しません。編集は既存Undo/Redo履歴へ保存されます。
